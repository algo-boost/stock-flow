## 一、用一句话说清楚

我们在机械臂**静止不动**的时候，看每个关节「为了扛住手臂和负载，用了多大的劲儿」，然后对比三份数据是不是一致：

1. **电脑算出来的**（仿真模型）
2. **驱动器直接报的力矩**（力矩反馈）
3. **根据电机电流推算的力矩**（电流反馈）

**测的目的：** 确认模型准不准、读数靠不靠得住，后面做碰撞检测、力控才有依据。

---

## 二、三个数到底是啥？（打个比方）

想象你单手拎一桶水，胳膊不动：

| 名字 | 通俗说法 | 技术说法 |
|------|----------|----------|
| **模型计算** | 按桶多重、胳膊什么角度，**理论上**胳膊应该用多大力 | MuJoCo 仿真算的理论力矩 |
| **力矩反馈** | 关节里像有个**测力计**，直接读出用了多大力（单位 Nm） | 读寄存器 `0x303A`，monitor 里「力矩」那一列 |
| **电流反馈** | 电机为了出力要多用电，根据**用电多少反推**用了多大力 | 读 `0x6077` 千分比，再套公式换算成 Nm |

**记住两句：**

- **力矩反馈** = 直接测量，**更可信**，验收主要看它。
- **电流反馈** = 推算出来的，要和力矩反馈、模型互相印证；1、2 轴上推算也很准。

它们测的是**同一件事**（关节用了多大力），只是来源不同，所以不会完全一样，但**差太多就有问题**。

---

## 三、电流反馈那个公式（不用背，知道干啥就行）

```
关节力矩 = 101 × 电机额定扭矩 × 千分比 ÷ 1000
```

- **101**：减速比（电机转很多圈，关节才转一圈，力会放大 101 倍）
- **额定扭矩**：电机铭牌上的参数（1、2 轴是 1.68，3～5 轴是 0.84，6、7 轴是 0.6）
- **千分比**：monitor 里 `0x6077` 那一列，比如 401 表示大约用了额定的 40%

**举例（1 轴，5kg 负载）：** 算出来约 67.9 Nm，和模型 68.1 Nm 几乎一样 → 说明这套标定是对的。

## 四、怎么测？（四步，现场流程）

```
仿真摆姿势 → 实机摆到一样 → 等停稳 → 读数记下来
```

| 步骤 | 做什么 |
|------|--------|
| **① 仿真** | 打开 MuJoCo，加载 `5KGarm.urdf`，Reset 归零，把手臂摆到「这一轴最吃力」的姿势 |
| **② 记角度** | 看仿真里每个关节多少度（7 个数） |
| **③ 实机** | 用 `stability_left_test.py` / `stability_right_test.py`，把 7 个角度填进去，让真手臂动到同样姿势 |
| **④ 读数** | 等完全停住，运行 `monitor.py`，记下「力矩」和 `0x6077`；需要时用 ethercat 再读一次核对 |

**负载条件：** 5kg、3kg、无负载，左右臂都测过。

**轴和从站号：** 1 轴对应 `-p 0`，2 轴 `-p 1` … 7 轴 `-p 6`；左臂 `-m 0`，右臂 `-m 1`。

## 五、结果怎么样？（按轴说，领导问哪轴答哪轴）

### 总体一张表

| 轴 | 一句话结论 |
|:--:|------------|
| **1 轴** | 很好，推算和模型几乎一样（误差约 0.3%）。左臂 3kg 有一个点偏差大，建议复测。 |
| **2 轴** | 很好，和 1 轴类似，大关节标定可靠。 |
| **3 轴** | 还行，力矩反馈更接近模型；两种读数方向一致。 |
| **4 轴** | **读数比模型一直偏大**（大约 15%～40%），但两种读数彼此接近 → **更像是模型不准**（摩擦、重量没建对），不是仪表坏了。 |
| **5 轴** | 力矩反馈还行；电流推算偏高约 15%～20%。 |
| **6 轴** | 大负载时和 4 轴类似偏大；小负载有个异常点，要复测确认。 |

### 怎么记颜色（和详细版一致）

- 🟢 1、2 轴：放心用电流推算做监控
- 🟡 3、5 轴：验收看力矩反馈
- 🔴 4 轴：先改模型，别只调公式
- 🟠 6 轴：先复测，再定结论

## 六、结论（汇报时念这三条）

**第一条 — 读数定义搞清楚了**

- 力矩反馈（monitor「力矩」列）= 直接读的，单位 Nm，**不用再乘 101**。
- 电流反馈 = 用 `0x6077` 加公式算出来的，不是另外接了一个电流表。

**第二条 — 大关节标定可信**

- 1、2 轴在 5kg 负载下，和模型误差 **小于 5%**，说明电机参数、减速比 101 这套是对的。

**第三条 — 中小关节问题在模型，不在仪表**

- 4、6 轴：两种读数彼此接近，但都高于模型 → **动力学模型或摩擦参数要改**，不是驱动器乱报数。
- 6 轴有个异常点要复测；空载力矩不为零时可以做零偏校准（`0x3801`）。

## 七、领导可能问的 → 你怎么答

| 领导问 | 你可以答 |
|--------|----------|
| **测了啥？** | 手臂静止时各关节用了多大力，和电脑算的对比，看模型和仪表是否一致。 |
| **为啥有三种数？** | 算是理论值；力矩反馈是直读；电流反馈是根据电机出力反推。三个应该接近。 |
| **以哪个为准？** | **验收以力矩反馈（0x303A）为准**；1、2 轴电流推算也很准，可以日常监控用。 |
| **4 轴为啥不准？** | 不是表不准，两种读数还一致，是**仿真模型**可能少了摩擦或重量不对，要建模同事改 URDF。 |
| **无负载为啥还有 30 多 Nm？** | 无负载不是「零力矩姿态」——手臂仍有自重，而且模型里「无负载」的定义要和仿真同事对齐。 |
| **下一步干啥？** | P0：复测 1 轴左臂 3kg、6 轴异常点；P1：改 4、6 轴模型；P2：标准化测试姿态和自动记录。 |
| **文档啥时候定稿？** | 6 月 23 日对齐口径后，2～3 个工作日出定稿。 |

## 八、常用命令（现场演示用）

```bash
# 看实时数据（右臂示例）
python3 /opt/project/motor_servo/scripts/monitor.py --shm /shm_right_arm7 --hz 1 --once

# 直接读某一轴力矩（右臂 1 轴，-p 0）

```

看 monitor 输出时指这两列：

- **力矩** → 力矩反馈（Nm）
- **0x6077** → 千分比，代入公式得电流反馈
