# 物料出入库管理系统 — MVP 功能需求文档

> **文档状态**：v1.2 — 2026-06-16 整理定稿，供 GitHub / 开发同步 / 现场试用  
> **上位文档**：[产品设计文档.md](./产品设计文档.md)、[架构设计文档.md](./架构设计文档.md)、[优化功能需求文档.md](./优化功能需求文档.md)

## 1. 文档目的

在 MVP 组合方案（Bitable + 飞书 H5 + FastAPI）不变的前提下，**收敛今日必须交付的能力**，让肖方方（库管）能在真实流程中完成「搜物料 → 看库存库位 → 出入库 → 查流水」，开发侧（金泓宇）可按本文档对齐剩余联调项。

**原则**：记清楚、找得到、可追溯 — 不扩成 ERP / WMS。能力框架见 **§2** （权限、查得到、管得住、可追溯、防断货）。

---

## 2. 产品能力框架

> 来源：产品手写纪要（2026-06-16）整理。系统按五块验收：**权限清晰、查得到、管得住、可追溯、防断货**。

### 2.1 权限 / 用户 — 清晰


| 角色      | 系统代码     | 说明                     |
| ------- | -------- | ---------------------- |
| 普通用户    | `USER`   | 搜索、出库、查本人记录            |
| 库管员     | `KEEPER` | + 入库、移动、库位/物料维护        |
| 系统管理员   | `ADMIN`  | 超级管理员：纠错、配置、导出、Mock 种子 |
| 供应链（协作） | 飞书群（P2）  | 审批发起人，**默认无入库写权限**     |


- **交易**：所有库存变更经出入库流水，不按「买卖」单独建模块。
- **落地**：飞书群成员 = 角色；App 展示「我的权限」，不在网页勾选 RBAC。


| 阶段  | 状态            |
| --- | ------------- |
| MVP | ✅ 三角色 + 接口鉴权  |
| P2  | 供应链群边界 + 审批身份 |


### 2.2 查得到 — 用户自助

从**用户视角**按**结构**自助查找，不靠问人：


| 维度            | 能力                             | 阶段    |
| ------------- | ------------------------------ | ----- |
| **货架 / 库区角度** | 电器 / 机械 / 维修 / 暂存四大类 + 二级中类折叠树 | MVP ✅ |
| **库位角度**      | 搜索展示「物料在哪柜、库存多少」；库位页维护         | MVP ✅ |
| **关键词**       | 名称、品牌、型号、规格、分类；空格多词 AND        | MVP ✅ |
| 扫码            | 扫条码定位                          | P1    |


### 2.3 管得住 — 管什么

**管什么**（核心对象）：


| 对象          | 管什么                 | 增删改     | 阶段    |
| ----------- | ------------------- | ------- | ----- |
| **出入**      | 入库、出库、库内移动；库存只经流水变更 | 流水只追加   | MVP ✅ |
| **货架 / 库位** | 库区、货柜命名、停用；有库存不可删   | 库管增删改停用 | MVP ✅ |
| **货物 / 物料** | 主数据、分类挂靠            | 库管维护物料  | MVP ✅ |


**流程管控**：


| 流程     | 说明                       | 阶段          |
| ------ | ------------------------ | ----------- |
| **审批** | 领用 / 补货 / 到货 → 飞书审批，再出入库 | **P2**      |
| **买卖** | 采购在飞书外完成；到货由库管入库记账       | MVP 仅「入库」   |
| **借还** | 个人借、还                    | **不做**（未立项） |


> 原则：**谁改库存谁负责** — 仅 KEEPER 经 H5 改账面；供应链不替代库管记账。

### 2.4 可追溯 — 谁干了什么


| 角色       | 能追溯什么                          | 阶段    |
| -------- | ------------------------------ | ----- |
| **管理员**  | 全量流水、纠错反向单、Bitable 修订历史        | MVP ✅ |
| **普通用户** | **查自己** —「我的记录」按 `operator` 过滤 | MVP ✅ |
| 全员       | 物料详情页该物料全部流水                   | MVP ✅ |


### 2.5 防断货


| 能力         | 说明                       | 阶段    |
| ---------- | ------------------------ | ----- |
| **阈值设定**   | 物料 `min_stock` 安全库存，库管维护 | P1 字段 |
| **缺货预警**   | 库存 < 阈值时列表/详情标红          | P1～P2 |
| 低库存清单 / 通知 | 筛选项、CSV、飞书推送             | P2～P3 |


> 手写纪要圈注 **MVP**：首期至少具备阈值字段 + 可见标红（与优化文档需求 6 一致）。

## 3. MVP 一句话

飞书工作台打开 H5 → 搜物料、看出入库与库位 → 库管维护库位与入库 → 全员出库领用 → 流水可追溯。

## 4. 今日交付范围（必须能用）

### 4.1 页面（H5）


| 页面      | 路由               | 角色           | 今日状态                    |
| ------- | ---------------- | ------------ | ----------------------- |
| 搜索 / 首页 | `/`              | 全员           | ✅ 组合关键词搜索、大类+中类折叠树、库存卡片 |
| 出库      | `/outbound`      | 全员           | ✅                       |
| 入库      | `/inbound`       | KEEPER、ADMIN | ✅                       |
| 库内移动    | `/transfer`      | KEEPER、ADMIN | ✅                       |
| 库位管理    | `/locations`     | KEEPER、ADMIN | ✅ 增删改停用；**不覆盖用户已建库位**   |
| 物料详情    | `/materials/:id` | 全员           | ✅ 分库位库存 + 流水            |
| 我的记录    | `/me/records`    | 全员           | ✅ 本人出库流水                |


### 4.2 核心能力


| #   | 能力       | 验收标准                                                                         |
| --- | -------- | ---------------------------------------------------------------------------- |
| 1   | **组合搜索** | 空格分隔多词，每词须命中名称/编码/品牌/型号/规格/分类名之一；例：`达妙 DM-J4340`、`禾赛 雷达`                     |
| 2   | **分类浏览** | 电器类 / 机械类 / 维修类 / 暂存区 → 二级中类折叠筛选                                             |
| 3   | **四大库区** | 电器 `ZONE_ELEC`、机械 `ZONE_MECH`、维修 `ZONE_MAINT`、暂存 `ZONE_STAGING`；维修区仅**待修坏件** |
| 4   | **出入库**  | 写流水 + 更新库存；普通用户不可直接改库存表                                                      |
| 5   | **库位维护** | 库管可新增/改名/删空库位/停用；**禁止删有库存库位**                                                |
| 6   | **权限**   | USER / KEEPER / ADMIN；飞书群判定（联调）或 Mock 头（本地）                                  |


### 4.3 明确不做（MVP）

- 三级分类细类、格位（柜-层-列）、**飞书审批流（P2）**、采购 ERP、借用续借、网页勾选 RBAC、Excel 导出（可 P2）

## 5. 数据与库区约定

### 5.1 库位（肖方方已建四柜，以现场为准）


| 分区  | zone 代码        | 用途                    |
| --- | -------------- | --------------------- |
| 电器类 | `ZONE_ELEC`    | 电机、相机、雷达、算力、交换机等      |
| 机械类 | `ZONE_MECH`    | 全向轮、夹爪、减速器、锂电池等       |
| 维修类 | `ZONE_MAINT`   | 故障待修件（坏电机等），**非**螺栓工具 |
| 暂存区 | `ZONE_STAGING` | 快递待到货                 |


**硬规则**：种子数据 / 导入脚本 **不得修改、删除** 用户已建库位 ID；仅写入物料与库存。

### 5.2 实验室初始物料（14 SKU，已支持一键导入）


| 物料                           | 数量    | 库区      |
| ---------------------------- | ----- | ------- |
| 达妙电机                         | 16    | 电器      |
| 同川关节电机模组                     | 1     | 电器      |
| 鸣志低压直流伺服电机                   | 1 + 3 | 电器 + 机械 |
| Realsense / 奥比中光相机           | 2 + 1 | 电器      |
| 激光雷达、交换机、伺服驱动板、GPU 大脑、CPU 小脑 | 各见清单  | 电器      |
| 八寸全向轮、夹爪、减速器、锂电池             | 见清单   | 机械      |


导入接口（仅 mock / 管理员）：`POST /admin/mock/seed-lab-materials`（不改库位）。

## 6. 角色与肖方方试用路径

### 6.1 肖方方（库管 KEEPER / ADMIN）

**今日 Mock 本地试用（浏览器）**

1. 打开 [http://localhost:5173（或团队](http://localhost:5173（或团队) ngrok 地址）
2. `frontend/.env`：`VITE_MOCK_ROLE=KEEPER` 或 `ADMIN`
3. 确认库位页四个库区已在
4. 搜索页验证 14 条物料与库存摘要
5. 走一遍：**入库 → 出库 → 移动 → 详情查流水**

**飞书正式试用（联调完成后）**

1. 工作台打开网页应用 → 自动免登
2. 飞书群配置 KEEPER/ADMIN 角色
3. `BITABLE_MODE=real` 读写真实 Bitable

### 6.2 研发（USER）

搜索 → 看出库库位 → 出库填用途 →「我的记录」查本人流水。

```powershell
# 后端 mock
cd backend
$env:BITABLE_MODE="mock"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010 --reload

# 前端（代理 → 8010）
cd frontend
npm run dev
```

Invoke-RestMethod -Method POST -Uri "http://localhost:5173/api/admin/mock/seed-lab-materials" -Headers @{"X-Mock-Role"="ADMIN"; "Content-Type"="application/json"} -Body "{}"
